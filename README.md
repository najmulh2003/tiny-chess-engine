A 4 KB Python chess engine: 0x88 board, alpha-beta with quiescence search, transposition table and iterative deepening to a fixed node budget. No clock, no randomness, no model calls.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
